Appearance and interaction differences
  • No Create Part Studio entry in Chili3D’s bottom + menu.
  • Search opens a centered modal; “Corner rectangle” finds no tool, while “Rectangle” does.
  • Selecting the offset-plane row after starting Sketch does not choose the sketch plane; the picker’s own Plane1 button works.
  • Extra floating tool badges, a taller sketch panel, and a viewport display label overlapping the Plane panel header.
  • Rectangle previews lack Onshape’s transient width/height labels.
  • The Loft is a horizontal legacy command, without profile ordering or editable feature history.
Fixes and verification in this change
  • Constrained circle trim now retargets circle-only constraints to the surviving arc. Browser hover, trim, undo and redo verified.
  • Invalid Loft confirmation is rejected before any source sketch is consumed.
  • Saved thumbnails use the fitted 320 × 200 model rendering; dashboard images retain their aspect ratio.
  • 681 relevant tests pass; TypeScript check and production build pass.

Remaining: the parametric Loft workflow and full Onshape/FeatureScript equivalence are not implemented or established by this comparison. The squares were cursor-drawn; this is a workflow test, not an exact volume comparison.
